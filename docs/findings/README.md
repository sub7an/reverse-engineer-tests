# Findings

Start with **[corrections-and-score-simulation.md](corrections-and-score-simulation.md)**:
what survived the held-out check, what was withdrawn, and what the surviving
signals are worth in marks.

Then **[convergence-and-key-structure.md](convergence-and-key-structure.md)**:
two later tests that found new signals, including the first one on reading
questions and the first strategy worth more than one question per exam.
Held-out figures in the older reports below predate these tests.

| Report | Data |
|---|---|
| [sat-question-bank.md](sat-question-bank.md) | College Board SAT Question Bank, 3,292 multiple-choice questions |
| [act-cracked.md](act-cracked.md) | 4 official ACT forms, 684 questions |
| [regents-ela-cracked.md](regents-ela-cracked.md) | 33 NY Regents English exams, 789 questions |
| [regents-subjects-cracked.md](regents-subjects-cracked.md) | 100 NY Regents US History, Global History and Living Environment exams, 4,720 questions |

The reports mention evidence folders (`pipeline-evidence/`,
`regents-evidence/`, `act-evidence/`). Those hold parsed question text, which
belongs to the publishers, so they are not in this repository. To reproduce a
result, download the papers from the publisher's archive and run the
pipeline.
